# Acompanhamento_Egressos_na_Rede_Federal
Este repositório apresenta o painel BI da Pesquisa de Acompanhamento de Egressos (PAE) do IFRN e a base de dados que alimenta. O painel no Google Looker Studio transforma dados brutos em visuais dinâmicos, a interface interativa oferece filtros para recortes específicos, permitindo segmentar métricas e extrair relatórios analíticos.
